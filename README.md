# VR Urban Mobility Simulator

A browser-based immersive urban mobility simulation environment designed for studying pedestrian and cyclist behavior in urban intersections using Extended Reality (XR) concepts.

This project combines interactive 3D visualization, real-time simulation, and research-oriented telemetry for transportation safety and behavioral studies.

---

## Features

- Interactive urban intersection simulation
- Pedestrian and cyclist behavior modeling
- Real-time telemetry dashboard
- VR-style immersive interface
- Traffic interaction visualization
- Research-oriented HUD system
- Adjustable simulation parameters
- Browser-based 3D environment
- Experimental mobility research prototype

---

## Technologies Used

- Three.js
- React JSX
- JavaScript
- HTML5
- CSS3
- WebGL

## Installation

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/vr-urban-mobility-simulator.git
```

### Open the Project

```bash
cd vr-urban-mobility-simulator
```

---

## Running the Project

Because browsers restrict local module loading, it is recommended to use a local development server.

### Using VS Code Live Server

1. Open the project in VS Code
2. Install the Live Server extension
3. Right click `index.html`
4. Click `Open with Live Server`

---

### Using Node.js

```bash
npx serve
```

Then open:

```text
http://localhost:3000
```
