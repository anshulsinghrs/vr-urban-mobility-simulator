# VR Urban Mobility Simulator

An immersive browser-based XR mobility simulator for studying pedestrian and cyclist interactions in urban environments.


## Features

- Urban intersection simulation
- Pedestrian & cyclist behavior modeling
- Real-time telemetry HUD
- VR-inspired interface
- Adjustable simulation parameters
- Browser-based 3D visualization

---

## Tech Stack

- Three.js
- React JSX
- JavaScript
- HTML/CSS
- WebGL
